# 账单导入

## 支持范围与使用流程

电脑从侧栏“账单导入”进入，手机从“账本与设置”进入。先添加实际账户，再选择文件，依次完成“支付账户 → 核对账目 → 确认入账”。无账户时可直接从导入页打开添加账户。PDF 密码和缺失年份的账单月份属于选填高级选项。核对阶段固定显示已选、尚未决定和需补全数量，可返回前一步修改。

| 来源 | 可读取格式 | 方向与日期语义 |
| --- | --- | --- |
| 微信个人对账 | CSV、XLSX、XLS | 使用收/支与交易时间 |
| 支付宝个人对账 | UTF-8/GB18030 CSV、Excel | 使用收/支，兼容列顺序变化 |
| 招行储蓄卡 | 文字版 PDF、CSV、Excel | 负数支出，正数收入 |
| 招行信用卡 | 文字版 PDF、CSV、Excel | 正数消费，负数还款或退款；月日结合账单年月处理跨年 |

仅处理人民币个人账单。ZIP 先解压，扫描 PDF 无法直接读取；支付宝缺少支付账户的旧网页版 TXT、商户结算账单不在支持范围。文本表格按内容表头识别，扩展名可为 csv/txt/tsv，但扩展名本身不保证兼容。

每个文件最多 10 MiB、5000 笔，PDF 最多 100 页，单次确认 1 至 500 笔。PDF 版式可能变化，确认前需核对日期、笔数和金额；无法识别时可尝试支持的 CSV。公开样例和合成测试不能证明所有真实文件兼容。

CSV 按表头定位，保留长订单号与前导零，支持引号、嵌入换行、千分位、BOM 和尾随制表符。无法解析的行保留在预览并阻止选择。

PDF 根据表头坐标划列：借记卡按相邻记账日期之间的中线分行，信用卡按记账日同行识别；保留分页表头，优先用信用卡账单标题年月，避免误读另一处账单日。格式字段与解析细节以 `parser.ts` 和 `pdf.ts` 为准。

## 映射与预览

原始支付方式映射到已有账户，只有尾号或名称唯一匹配时才建议账户；未知或多义匹配需要手工选择。分类取当前启用分类并给出可修改建议。

预览按普通收支、退款与冲正、资金往来、信用卡还款、疑似重复、无法导入分组，可再按支付方式和原始分类缩小批量处理范围。普通收支默认选择入账；特殊记录初始为“尚未决定”，与用户主动“跳过”区分。坏行、已导入来源标识、文件内重复标识归为无法导入，禁止选择；疑似重复允许用户明确保留。

批量设置作用于当前分组及支付方式、原始分类范围的所有页，不受明细状态筛选影响。可重复调整批量设置，但不会覆盖单独修改过的记录。保留原收支时逐笔沿用账单方向；转账和还款需指定两个有效账户，并遵守[记账规则](ledger.md)。退款可暂不导入并手动修正原账，选择记为收入会增加收入统计。明细仍可逐笔修改，缺少账户或分类的已选记录可集中筛选补全。

已选、尚未决定、主动跳过、无法导入与本次预览已导入的计数分别展示；只有已选记录参与入账。确认前显示本批笔数与金额及排除的记录数。超过 500 笔按文件顺序分批确认，每批成功后保留剩余预览和已选设置，生成新的批次 ID；失败沿用原批次 ID 重试。账本内切换功能会保留当前导入核对内容；结束预览或重新选文件前需确认放弃尚未入账的选择，已成功导入的批次保留。内容只保留在当前页面内存，刷新或离开页面会提示，确认离开后不会恢复。
退款不自动关联或冲减原消费；平台与银行卡记录不自动合并。历史导入会改变账户余额；若建账户时用了今日余额，导入历史后应再次核对余额。

## 两种重复判断

硬去重按账本、来源、来源标识保存：微信和支付宝用订单号；无订单号的招行记录依据原始日期、金额、摘要、对手、卡尾号及相同记录出现次数构造标识，再加上映射银行账户。同一无订单流水在不同文件中的出现次数可能不同，因此不能只依赖硬去重。

软提示对比同日、同金额、同账户同方向的已有交易，默认跳过，可明确保留。跨平台记录只做提示，不擅自合并。

来源记录不通过交易外键级联删除，所以单笔账目删除后仍保留硬去重标识；如需释放，应使用安全的整批撤销。

## 提交、重试与撤销

确认时走统一账本命令和版本锁。服务端重新生成分录，在一个事务内保存全部选中交易、批次与来源记录，任一行无效全部回滚。数据库对账本/来源/标识建立唯一约束。

相同批次 ID 再提交时，若批次仍有效，领域逻辑直接返回现有账本，避免重复插入；仓储仍会先校验 revision，并在成功命令后递增版本。已撤销的 ID 不可复用，需重新预览。

整批撤销逐条核对当前交易签名：存在手动修改或关联报销则拒绝，需逐笔处理。安全撤销删除仍存在的批内交易，释放来源去重记录，保留标记为已撤销的批次历史，随后可重新导入。已经单独删除的交易不阻止安全撤销。

## 隐私与实现依据

原文件和 PDF 密码只在浏览器解析；确认时提交规范化账目、文件名及去重标识。无订单标识可能包含原摘要，不应把导入元数据视为无敏感内容。Excel 与 PDF 库按需加载，PDF worker 同源提供。
